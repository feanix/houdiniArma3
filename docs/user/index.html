A3OB for Houdini

Make and edit Arma 3 models (.p3d files) in Houdini.

These pages explain the nodes and shelf tools that read a .p3d file into Houdini, let you edit it, check it, and write it back so Arma can use it. They are written for two kinds of reader: Arma modders who are new to Houdini, and Houdini users who are new to Arma.

  • ReferenceEvery node and shelf tool, with all parameters.

In Houdini, select an A3OB node and click the ? (help) icon at the top right of the parameter pane, or press F1 over the node. The help page that opens names the full reference page for the node by its path in the add-on folder.

Houdini tools for Arma 3 models. Based on Arma 3 Object Builder by MrClock, which continues ArmAToolbox by Alwarren.
