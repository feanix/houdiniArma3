Install

How to put the add-on in Houdini, check that it works, and update it later.

The add-on is a folder of files. Houdini finds it through a package file: a small text file that tells Houdini where the add-on lives and which parts to load. You do not run an installer.

What you need

  • Houdini 22.0 or later. The package file does not load in an older Houdini. Houdini Indie works.
  • The add-on folder. Download it or clone it from its repository. This page calls it the add-on folder. It is the folder that holds packages, houdini and python. The examples use E:/Projects/houdiniArma3. Use your own path, with forward slashes.

Step 1: tell Houdini about the add-on

Pick one of the two ways below. Way A is how the author installed it.

Way A: copy the package file

  1. Open your Houdini preferences folder. On Windows it is Documents/houdini22.0. If it has no packages folder, make one.
  2. Copy packages/a3ob_houdini.json from the add-on folder into that packages folder.
  3. Tell the copy where the add-on folder is. A copied file cannot work that out by itself. Set the environment variable A3OB_HOUDINI to the add-on folder. The simplest way is one line in Documents/houdini22.0/houdini.env: 
    A3OB_HOUDINI = "E:/Projects/houdiniArma3"
    A system environment variable with the same name works too.

Instead of the environment variable you can edit the copy. In its first env entry, replace ${A3OB_HOUDINI-$HOUDINI_PACKAGE_PATH/..} with the path of the add-on folder.

Way B: point Houdini at the add-on folder

Set the environment variable HOUDINI_PACKAGE_DIR to the packages folder inside the add-on folder, for example E:/Projects/houdiniArma3/packages. Set it before Houdini starts. Nothing is copied. The package file finds the add-on folder on its own, because it sits next to it.

Use Way B if you want several package folders or do not want to touch your preferences folder. If you use both ways at once, Houdini sees two copies of the package. Use only one.

What the package file does

It sets A3OB_HOUDINI (if you have not), adds the add-on's houdini folder to Houdini's search path so that it finds the nodes and the shelf, and adds the add-on's python folder so that the tools can run their Python code.

Step 2: restart Houdini

Close Houdini and start it again. Houdini reads package files only at start-up.

Step 3: add the A3OB shelf

The shelf is the row of tool buttons above the viewport. The add-on brings a shelf called A3OB, but Houdini does not show it until you ask.

  1. Click the + button at the right end of the shelf tabs.
  2. Choose Shelves, then A3OB.

A new tab appears with six tools: Selection browser, Quick Export, New P3D, Batch folder convert, Project root and presets and Reload A3OB.

Every tool has a page in the reference.

Step 4: check that it loaded

Do any one of these.

  • Tab menu. Open a Geometry object (see the quick start). In the network editor, press Tab. The menu has a submenu called A3OB with nine nodes in it.
  • Python shell. Open Windows, then Python Shell, and type: 
    import a3ob_houdini
hou.getenv("A3OB_HOUDINI")
hou.nodeType(hou.sopNodeTypeCategory(), "a3ob_p3d_import")
    The first line must not give an error. The second prints your add-on folder. The third prints a node type, not None. The type name a3ob_p3d_import is the Houdini name of the P3D Import node.
  • Help. Create a P3D Import node, select it and click the ? (help) icon at the top right of the parameter pane, or press F1 over the node. Houdini's help opens a short page for the node. That page names the full reference page by its path in the add-on folder, docs/user/reference/a3ob_p3d_import.html. You can open that file in your browser.

If it did not load

  • No A3OB submenu: check that you restarted Houdini, that the package file is in the folder packages of the preferences folder you use (or that HOUDINI_PACKAGE_DIR is set), and that your Houdini is 22.0 or later.
  • The menu is there but a node says it cannot import a3ob_houdini: the add-on folder path is wrong. Check A3OB_HOUDINI and look for a python folder inside the path it names.
  • Houdini prints package problems in its console. On Windows, start Houdini from a terminal to see them.

Update later

  1. Replace the add-on folder with the new version (or pull the new files).
  2. In Houdini, click Reload A3OB on the A3OB shelf. It makes Houdini forget the old A3OB code and load the new code, without a restart. Nodes you cook after that use the new code.
  3. If a node looks wrong after an update (a missing parameter, for example), restart Houdini.

Reload A3OB works from the shelf, so it does not help if the shelf itself did not load. Restart Houdini in that case.
