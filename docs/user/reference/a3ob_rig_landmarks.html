Rig Landmarks

Marks the landmarks of your character (chin, groin, shoulders, elbows, wrists, hips, knees, ankles) for Rig Fit, one field each.

Rig Fit fits the skeleton to 14 landmarks of your character. This node is the easy way to set them: it has one field for each landmark (chin, groin, and left and right shoulder, elbow, wrist, hip, knee and ankle). Click the arrow button next to a field, select the points in the viewport and press Enter. Put the node between your mesh and Rig Fit.

The node writes a point group lm_<landmark> for each field that is set. A field that is empty writes no group, and Rig Fit guesses that landmark. A group that is already on your mesh is kept when its field is empty and replaced when the field is set. The message lists which landmarks are set and which are left to the guess; a field that matches no points is a warning.

Houdini namea3ob_rig_landmarks
Where to find itTab menu, A3OB, Rig Landmarks
Inputs1

Inputs

  1. Input 1: Your mesh. Your character mesh, the one that goes into Rig Fit.

Parameters

Parameters are in the order they appear on the node.

Chin lm_chin

The tip of the chin. Select the points in the viewport with the arrow button. The average of the points is the landmark. Leave it empty to let Rig Fit guess this landmark.

Type
Group picker (text; the menu lists the point groups of the input, the arrow button picks in the viewport)
Default
(empty)

Groin lm_groin

The crotch, the highest point between the legs. Select the points in the viewport with the arrow button. The average of the points is the landmark. Leave it empty to let Rig Fit guess this landmark.
