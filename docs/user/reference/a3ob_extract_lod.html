Reference / Nodes

Extract LOD

Takes one LOD out of a P3D geometry and outputs it as a LOD geometry that you can edit.

P3D Import gives you each LOD of a model packed into one primitive. This node unpacks the LOD you pick, so you can edit its points and polygons like any other Houdini geometry.

Houdini namea3ob_extract_lod
Where to find itTab menu, A3OB, Extract LOD
Inputs1

Inputs

  1. Input 1: P3D geometry. The geometry from P3D Import, with every LOD packed into its own primitive.

Parameters

Parameters are in the order they appear on the node.

LOD lod

Which LOD to extract: pick one from the menu, or type its position in the P3D geometry (0 is the first) or its name, for example Geometry or Resolution 1.

Type
Menu
Default
0

The choices are made when you open the menu, from the geometry or the settings.
