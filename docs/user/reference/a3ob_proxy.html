Reference / Nodes

Proxy

Adds proxies (references to other .p3d files, such as weapon slots or seats) as packed primitives.

A proxy marks a place where Arma puts another model, such as a weapon on a vehicle or a seat for a crew member. This node adds proxies to a LOD geometry.

With one input, the node adds a single proxy. With a second input, it adds one proxy for each point of that input.

Houdini namea3ob_proxy
Where to find itTab menu, A3OB, Proxy
Inputs1 to 2

Inputs

  1. Input 1: LOD geometry. The LOD that gets the proxy.
  2. Input 2: Points (one proxy per point). Optional. Each point of this geometry becomes one proxy, placed and turned by that point.

Parameters

Parameters are in the order they appear on the node.

Path path

The proxy model: pick a .p3d file, or type its game path, for example \a3\data_f\proxies\weapon_slots\top. A picked file such as P:\a3\data_f\proxies\weapon_slots\top.p3d gives the same name as typing it. Slashes become backslashes and the .p3d ending is removed. When you export with Relative Paths on, the path is mapped to the in-game path (see the Relative Paths tooltip of P3D Export).

Type
File path
Default
(empty)
Files
*.p3d

Common Proxies common

Fills Path with the game path of a frequently used proxy, such as a weapon slot or a seat.

Type
Menu
Default
(choose)

Choices:

  • (choose) none
  • Weapon: optic weapon_optic
  • Weapon: pointer weapon_pointer
  • Weapon: suppressor weapon_suppressor
  • Weapon: magazine weapon_magazine
  • Weapon: bipod weapon_bipod
  • Driver: offroad driver_offroad
  • Passenger: offroad passenger_offroad
  • Gunner: hunter gunner_hunter
  • Commander: hunter commander_hunter
  • Light volume: car light_volume_car

Index index

The proxy number, 0 to 999. The game needs a different number for each proxy with the same model in one LOD.

Type
Whole number
Default
1
Allowed
From 0 to 999

Number From Points autoindex

With a second input: the first proxy gets Index, the next one Index + 1, and so on. Off: all get Index.

Type
On or off
Default
On

Translate t

Where the proxy goes, in metres. Used when there is no second input.

Type
3 numbers
Default
0, 0, 0

Rotate r

How the proxy is turned, in degrees around X, Y and Z. A proxy has no scale.

Type
3 numbers
Default
0, 0, 0

Orient From Points useorient

With a second input: turn each proxy by the orient attribute of its point, if the point has one.

Type
On or off
Default
On
