Reference / Shelf tools

Quick Export

Exports the selected SOP node (or the display node of the current network) to a .p3d file with a preset. Adds no node.

Use this for a fast export without adding a node to your network. Pick a preset and a file name.

Where to find itThe A3OB shelf, button Quick Export
Tool namea3ob_quick_export

A shelf tool works on your scene or your settings when you click it. It is not a node, so it does not stay in your network.

Houdini tools for Arma 3 models. Based on Arma 3 Object Builder by MrClock, which continues ArmAToolbox by Alwarren.
