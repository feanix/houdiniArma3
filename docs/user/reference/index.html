Reference

Every node and shelf tool, with all of its parameters. In Houdini, click the ? icon at the top right of the parameter pane (or press F1 over the node) to read its help. This site has the same text.

A typical network

Most models follow this chain. Import a model, take one LOD out, edit it, put the LODs back together, check them and export.

  1. P3D Import
  2. Extract LOD
  3. Your edits
  4. Assemble LODs
  5. Validate
  6. P3D Export

Nodes

Add these from the Tab menu, in the A3OB submenu.

  • Assemble LODsPuts edited LODs back into a P3D geometry. Input 1 is the base; inputs 2 and up are LOD geometries.
  • ComponentsMakes the component groups (Component01, Component02, ...) of a Geometry LOD, one per connected piece.
  • Extract LODTakes one LOD out of a P3D geometry and outputs it as a LOD geometry that you can edit.
  • LOD PropertiesSets the LOD type, resolution, named properties and LOD copies of a LOD geometry.
  • MassSets the mass of each point of a Geometry LOD (the #Mass# data of the P3D file).
  • Material AssignSets the texture and the material (rvmat) of the polygons in a group, or of all polygons.
  • P3D ExportChecks a P3D geometry or a LOD geometry like Validate and writes it as a .p3d file when Save to Disk is pressed. The output is the input. Shadow and underground LODs are always written with hard edges (the geometry here is not changed).
  • P3D ImportReads an Arma 3 .p3d file (MLOD) and outputs one packed primitive per LOD.
  • ProxyAdds proxies (references to other .p3d files, such as weapon slots or seats) as packed primitives.
  • Rig FitFits the Arma skeleton and the sample body to your mesh, from landmarks that you set or that are guessed.
  • Rig LandmarksMarks the landmarks of your character (chin, groin, shoulders, elbows, wrists, hips, knees, ankles) for Rig Fit, one field each.
  • Rig SkeletonBuilds the Arma 3 character skeleton as a KineFX skeleton, from a model.cfg and a pivots .p3d file.
  • ValidateChecks a P3D geometry or a LOD geometry the way the export does and shows what is wrong. Changes nothing. Shadow and underground LODs are always written with hard edges, so the message line says when the export will do that.
  • Weight CleanupMakes the bone weights follow Arma's rules: at most 4 bones per point, weights in steps of 1/254, sum 1.
  • Weight TransferCopies the bone weights of a source body (the sample character) onto your mesh, with layers for rigid and loose parts.
  • Weights ConvertConverts bone weights between P3D selections (point groups) and KineFX capture weights for the skeleton.

Shelf tools

These are the buttons on the A3OB shelf.

  • Selection browserLists the point groups of the selected SOP node by their P3D name. Copies an encoded name, or adds a Group, Group Delete or Group Rename node.
  • Quick ExportExports the selected SOP node (or the display node of the current network) to a .p3d file with a preset. Adds no node.
  • New P3DBuilds the starter network (Resolution 1, Geometry and Memory LODs, Assemble LODs, P3D Export) in the open SOP network or in a new Geometry object.
  • Batch folder convertRe-exports every .p3d in a folder with a preset into an output folder and writes a report: identical, different or failed for each file. The sources are never changed.
  • Project root and presetsSets the project root, picks, edits and deletes export presets, sets the common data file, and sets the Arma 3 Samples folder that the rigging nodes start from. Stored in one JSON file in the Houdini user preferences. Changes nothing in a scene.
  • Reload A3OBLoads the A3OB code again after the package was updated, without restarting Houdini.
