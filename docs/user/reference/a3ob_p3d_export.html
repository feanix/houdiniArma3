Reference / Nodes

P3D Export

Checks a P3D geometry or a LOD geometry like Validate and writes it as a .p3d file when Save to Disk is pressed. The output is the input.

This node is the end of a network. It checks the geometry the way Validate does and, when you press Save to Disk, writes a .p3d file you can use in Arma. The output is the same as the input, so you can keep working after it.

Houdini namea3ob_p3d_export
Where to find itTab menu, A3OB, P3D Export
Inputs1

Inputs

  1. Input 1: P3D geometry or LOD geometry

Parameters are in the order they appear on the node.

Type

Choices:

  • Every cook cook: check whenever the node cooks.
  • When saving save: check only on Save to Disk (for large models).

Errors Show As errorlevel

Type
Menu
Default
Error (stop here)

Choices:

  • Error (stop here) error: the node turns red and the nodes below it stop.
  • Warning (keep geometry) warning: the node turns yellow and the geometry keeps flowing; the text still starts with Error:. Saving stops on errors either way.

Warnings Count As Errors strict

Treat every warning as an error. Off by default: a warning can be what you meant.
