Reference / Nodes

P3D Export

Checks a P3D geometry or a LOD geometry like Validate and writes it as a .p3d file when Save to Disk is pressed. The output is the input.

This node is the end of a network. It checks the geometry the way Validate does and, when you press Save to Disk, writes a .p3d file you can use in Arma. The output is the same as the input, so you can keep working after it.

The options are in tabs. A new node starts from the preset that is active in the Project root and presets tool. In Selection Mask, type group names separated by spaces; a name may use * and ?, and ^ before a name leaves it out. The menu lists the input's point groups: picking one adds it to the mask or removes it. The info line on the node says how many selections will be written.

Houdini namea3ob_p3d_export
Where to find itTab menu, A3OB, P3D Export
Inputs1

Inputs

  1. Input 1: P3D geometry or LOD geometry. The model to check and write: a whole P3D from Assemble LODs, or a single LOD.
