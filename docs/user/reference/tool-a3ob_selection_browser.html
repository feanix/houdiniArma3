Reference / Shelf tools

Selection browser

Lists the point groups of the selected SOP node by their P3D name. Copies an encoded name, or adds a Group, Group Delete or Group Rename node.

In a P3D file, a selection (a named set of points or faces) has a name that Houdini group names cannot always hold as typed. This tool lists the groups of the selected node by their P3D name.

Where to find itThe A3OB shelf, button Selection browser
Tool namea3ob_selection_browser

A shelf tool works on your scene or your settings when you click it. It is not a node, so it does not stay in your network.

Houdini tools for Arma 3 models. Based on Arma 3 Object Builder by MrClock, which continues ArmAToolbox by Alwarren.
