Reference / Nodes

Material Assign

Sets the texture and the material (rvmat) of the polygons in a group, or of all polygons.

A polygon in a P3D file has a texture and a material (an rvmat file). This node sets them for the polygons in a group, or for all polygons.

Houdini namea3ob_material_assign
Where to find itTab menu, A3OB, Material Assign
Inputs1

Inputs

  1. Input 1: LOD geometry. The LOD whose polygons get the texture and material.

Parameters

Parameters are in the order they appear on the node.

Group group

Which polygons to set. Empty means all polygons. The menu lists the groups of the input (primitive groups or point groups, as Group Type says) and shows the P3D name of a selection; picking adds or removes the group. The arrow button picks in the viewport. You can also type group names, patterns or numbers like 0-3.

Type
Group picker (text; the menu lists the groups of the kind the Group Type menu sets of the input, the arrow button picks in the viewport)
Default
(empty)

  • Points points: The polygons whose points are all in the group.

Texture File texture

The texture file (.paa, .tga or .png). Slashes are written as backslashes. The export writes every ending but .paa as .paa (camo1_co.png becomes camo1_co.paa); making that .paa is up to you. When you export with Relative Paths on, the path is mapped to the in-game path (see the Relative Paths tooltip of P3D Export).

Show in Viewport showviewport

On: the polygons get a Houdini material that shows their texture in the viewport (one material per texture, in the network a3ob_viewport_materials inside the Geometry object). It only changes what Houdini shows; the P3D export ignores it. A .paa is shown from a .png, .tga or .tif of the same name next to it, else from a picture decoded from the .paa. A plain colour texture is shown as that colour. The material (rvmat) is not shown. In-game paths are only shown when the file is found under the project root. Materials that are no longer used stay in the network; they are harmless. Off: the polygons keep the Houdini material they came with.

Type
On or off
Default
On
