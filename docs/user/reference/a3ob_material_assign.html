Reference / Nodes

Material Assign

Sets the texture and the material (rvmat) of the polygons in a group, or of all polygons.

A polygon in a P3D file has a texture and a material (an rvmat file). This node sets them for the polygons in a group, or for all polygons.

Houdini namea3ob_material_assign
Where to find itTab menu, A3OB, Material Assign
Inputs1

Inputs

  1. Input 1: LOD geometry

Parameters

Parameters are in the order they appear on the node.

Group group

Which polygons to set. Empty means all polygons. Normal Houdini group syntax; a selection with an encoded name is easiest to pick in the Selection browser.

Type
Text
Default
(empty)

Group Type grouptype

Type
Menu
Default
Primitives

Choices:

  • Primitives prims: the polygons in the group.
  • Points points: the polygons whose points are all in the group.

4 numbers

Color Type colortype

For Color. The kind of procedural texture.

Type
Menu
Default
CO - Color Value

Choices:

  • CO - Color Value CO
  • CA - Texture with Alpha CA
  • LCO - Terrain Texture Layer Color LCO
  • SKY - Sky texture SKY
  • NO - Normal Map NO
  • NS - Normal map specular with Alpha NS
  • NOF - Normal map faded NOF
  • NON - Normal map noise NON
  • NOHQ - Normal map High Quality NOHQ
  • NOPX - Normal Map with paralax NOPX
  • NOVHQ - two-part DXT5 compression NOVHQ
  • DT - Detail Texture DT
  • CDT - Colored detail texture CDT
  • MCO - Multiply color MCO
  • DTSMDI - Detail SMDI map DTSMDI
  • MC - Macro Texture MC
  • AS - Ambient Shadow texture AS
  • ADS - Ambient Shadow in Blue ADS
  • PR - Ambient shadow from directions PR
  • SM - Specular Map SM
  • SMDI - Specular Map, optimized SMDI
  • MASK - Mask for multimaterial MASK
  • TI - Thermal imaging map TI
