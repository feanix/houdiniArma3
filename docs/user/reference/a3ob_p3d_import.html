Reference / Nodes

P3D Import

Reads an Arma 3 .p3d file (MLOD) and outputs one packed primitive per LOD.

Use this node to bring an existing Arma 3 model into Houdini. A P3D file holds one or more LODs (versions of the model for different viewing distances). The node outputs one packed primitive for each LOD. Wire it into Extract LOD to edit one of them.

Houdini namea3ob_p3d_import
Where to find itTab menu, A3OB, P3D Import
InputsNone

Parameters

Parameters are in the order they appear on the node.

File file

The .p3d model to open. Use the editable version Object Builder saves (MLOD). Files taken out of the game's packed PBOs (binarized, ODOL) can't be opened.

Type
File path
Default
(empty)
Files
*.p3d

Reload reload

Read the file again from disk, for example after you saved it in Object Builder.

Type
Button

LODs lods

Which LODs to bring in. Pick them from the menu, or type numbers or names. * means all. Picking from the menu replaces a * in the field, and a * next to other entries still means all.

Type
Menu (pick several; each pick adds or removes an entry in the text)
Default
*

The choices are made when you open the menu, from the geometry or the settings.

Explicit Face Groups facegroups

A face group is a named set of faces. Every selection comes in as a group of points. Normally a face group is added only when the selection's faces are not just the faces whose points are all in it. Turn this on to get a face group for every selection, for example when you want to select or blast faces by selection name.

Type
On or off
Default
Off
