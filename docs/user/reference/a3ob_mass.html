Reference / Nodes

Mass

Sets the mass of each point of a Geometry LOD (the #Mass# data of the P3D file).

Arma needs a mass for each point of a Geometry LOD to work out how a vehicle or object moves. This node sets that mass in one of several ways.

Houdini namea3ob_mass
Where to find itTab menu, A3OB, Mass
Inputs1

Inputs

  1. Input 1: LOD geometry. The Geometry LOD whose points get a mass.

Parameters

Parameters are in the order they appear on the node.

Mode mode

What to do with the mass.

Type
Menu
Default
Uniform total

Choices:

  • Set on each each
  • Uniform total total
  • From density density
  • Clear clear
  • Copy from mass copyfrom
  • Copy to mass copyto

Value value

Set on each: kilograms per point. Uniform total: kilograms shared by all the points. From density: kilograms per cubic metre. The value cannot be below 0; there is no upper limit (the slider shows 0 to 10, and you can type more).

Type
Number
Default
1
Allowed
At least 0; no upper limit

Group group

The points to change. Empty means all points.

Type
Text
Default
(empty)

Visualize visualize

Write the colour Cd: blue is the least mass, red the most, black no mass. The export ignores Cd.

Type
On or off
Default
Off
