Reference / Nodes

Mass

Sets the mass of each point of a Geometry LOD (the #Mass# data of the P3D file).

Arma needs a mass for each point of a Geometry LOD to work out how a vehicle or object moves. This node sets that mass in one of several ways.

Houdini namea3ob_mass
Where to find itTab menu, A3OB, Mass
Inputs1

Inputs

  1. Input 1: LOD geometry. The Geometry LOD whose points get a mass.

Parameters

Parameters are in the order they appear on the node.

Mode mode

How the mass is set. Only the number for the chosen way is shown.

Type
Menu
Default
Uniform total

Choices:

  • Set on each each: Gives every point the same mass, set by Mass per Point.
  • Uniform total total: Sets the mass of the whole object (Total Mass) and shares it equally among the points.
  • From density density: Works the mass out from the volume of each closed shape and the Density.
  • Clear clear: Removes the mass. With a group, only those points go back to 0.
  • Copy from mass copyfrom: Takes the mass from the point attribute called mass, which you made yourself.
  • Copy to mass copyto: Copies the mass into a point attribute called mass, so you can see it or use it elsewhere.

Mass per Point (kg) mass_each

The mass in kilograms that every point gets. It cannot be below 0. The slider shows 0 to 10, and you can type a larger number.

Type
Number
Default
1
Allowed
At least 0; no upper limit
Shown when
Mode is Set on each

Total Mass (kg) mass_total

The mass in kilograms of the whole object. It is shared equally among the points. It cannot be below 0. The slider shows 0 to 10, and you can type a larger number.

Type
Number
Default
1
Allowed
At least 0; no upper limit
Shown when
Mode is Uniform total

Density (kg/m³) density

The mass of one cubic metre of the material, in kilograms. Each closed shape gets its volume times this number. It cannot be below 0. The slider shows 0 to 10, and you can type a larger number.

Type
Number
Default
1
Allowed
At least 0; no upper limit
Shown when
Mode is From density

Value (old scenes) value

Not shown. Scenes saved before the three mass parameters existed stored the number here. When a scene loads, a number of 0 or more is moved into the parameter of the current mode and this goes back to -1. A new node leaves it at -1.

Type
Number
Default
-1

Group group

The points to change. Empty means all points. The menu lists the point groups of the input and shows the P3D name of a selection; picking adds or removes the group. The arrow button picks points in the viewport. You can also type group names, patterns or point numbers (for example 0-3).

Type
Group picker (text; the menu lists the point groups of the input, the arrow button picks in the viewport)
Default
(empty)

Visualize visualize

Colour the points in the viewport by their mass: blue is the least mass, red the most, black no mass. This is a node visualizer, so the geometry (and any Cd it has) is not changed. The export ignores it.

Type
On or off
Default
Off
