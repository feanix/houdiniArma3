Reference / Nodes

LOD Properties

Sets the LOD type, resolution, named properties and LOD copies of a LOD geometry.

Every LOD has a type (for example Visual or Geometry), a resolution number and a list of named properties. This node sets them on the LOD geometry that comes in.

Houdini namea3ob_lod_properties
Where to find itTab menu, A3OB, LOD Properties
Inputs1

Inputs

  1. Input 1: LOD geometry. The LOD whose type, resolution, properties and copies you want to set.

Parameters

Parameters are in the order they appear on the node.

Read from Input fromin

Copy the type, resolution, properties and copies of the input into the parameters below. Use it right after Extract LOD.

Type
Button

Set Type and Resolution settype

Off: leave the input's type and resolution alone and only edit properties and copies.

Type
On or off
Default
On

LOD Type lodtype

The kind of LOD.

Type
Menu
Default
Resolution

Choices:

  • Resolution visual: Visual resolution
  • View - Gunner view_gunner: Gunner first person view
  • View - Pilot view_pilot: First person view
  • View - Cargo view_cargo: Passenger first person view
  • Shadow Volume shadow: Shadow casting geometry
  • Edit edit: Temporary layer
  • Geometry geometry: Object collision geometry and occluders
  • Geometry Buoyancy geometry_buoy: Buoyant object geometry (Displacement for VBS)
  • Geometry PhysX geometry_physx: PhysX object collision geometry
  • Memory memory: Hard points and animation axes
  • Land Contact landcontact: Points of contact with ground
  • Roadway roadway: Walkable surfaces
  • Paths paths: AI path finding mesh
  • Hit-points hitpoints: Hit point cloud
  • View Geometry view_geometry: View occlusion for AI
  • Fire Geometry fire_geometry: Hitbox geometry
  • View - Cargo Geometry view_cargo_geometry: Passenger view collision geometry and occluders
  • View - Cargo Fire Geometry view_cargo_fire_geometry: Passenger view hitbox geometry
  • View - Commander view_commander: Commander first person view
  • View - Commander Geometry view_commander_geometry: Commander view collision geometry and occluders
  • View - Commander Fire Geometry view_commander_fire_geometry: Commander hitbox geometry
  • View - Pilot Geometry view_pilot_geometry: First person collision geometry and occluders
  • View - Pilot Fire Geometry view_pilot_fire_geometry: First person hitbox geometry
  • View - Gunner Geometry view_gunner_geometry: Gunner collision geometry and occluders
  • View - Gunner Fire Geometry view_gunner_fire_geometry: Gunner view hitbox geometry
  • Sub Parts subparts: Obsolete
  • Shadow Volume - Cargo View shadow_view_cargo: Passenger view shadow casting geometry
  • Shadow Volume - Pilot View shadow_view_pilot: First person view shadow casting geometry
  • Shadow Volume - Gunner View shadow_view_gunner: Gunner view shadow casting geometry
  • Wreckage wreckage: Vehicle wreckage
  • Underground (VBS) underground: Underground volume for VBS (not supported in Arma 3 -> Geometry PhysX Old)
  • Groundlayer (VBS) groundlayer: Ground deformation data for VBS (not supported in Arma 3 -> Shadow Volume 3000)
  • Navigation (VBS) navigation: Navigation data for VBS (not supported in Arma 3 -> Geometry / Resolution 5e+013)
  • Unknown unknown: Unknown model layer

Properties props_box

These parameters are in the Properties group box.

Properties props

Named properties of the LOD, such as autocenter or lodnoshadow. Each name and value can be up to 63 characters.
