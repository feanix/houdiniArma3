Reference / Nodes

Assemble LODs

Puts edited LODs back into a P3D geometry. Input 1 is the base; inputs 2 and up are LOD geometries.

A P3D file keeps several LODs (versions of the model for different viewing distances) together. After you edit LODs one at a time, this node puts them back together.

Input 1 is optional: it takes the original P3D geometry, so that the LODs you did not touch stay as they were. Every other input takes one LOD geometry.

Houdini namea3ob_assemble_lods
Where to find itTab menu, A3OB, Assemble LODs
Inputs0 to 32

Inputs

  1. Input 1: Base P3D geometry (optional). The original P3D geometry. LODs you do not replace are kept from it.
  2. Inputs 2 to 32: LOD geometry. One LOD to put into the model. It replaces the base LOD of the same type and resolution.

The node also works with no input connected.

Parameters

Parameters are in the order they appear on the node.

Replace Matching LODs replace

A LOD input replaces the base LOD that has the same stored LOD signature and keeps its position. A LOD with no match is added at the end. Off: every LOD input is added at the end.

Type
On or off
Default
On
