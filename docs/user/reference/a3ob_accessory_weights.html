Reference / Nodes

Accessory Weights

Weights accessories (a helmet, pouches, a strap) from points that already have weights: the body or another accessory.

Accessories do not follow the skin: a helmet turns with the head, a pouch with the belt, a bandolier bends with the chest. This node weights them from points that already have weights. Put the accessory points in the Target Group and the points that give the weights in the Source Group: the body, or another accessory (a pouch can take its weights from the belt). Chain one node per accessory after Weight Transfer, and run Weight Cleanup last.

Rigid mode gives every connected piece of the target one bone or one fixed blend. Auto picks the bone with the most source weight under the piece (a twist bone counts for the next bone down the chain); Fixed blend gives every point the average; Bone gives every piece the bone you pick from the menu of the skeleton. Non-rigid mode lets each point take the source weights under it and smooths them along the piece. A target point with no source point within the distance limit takes the nearest weighted source point, and the node warns with the count. The result is bone selections, a3ob_rig_origin (3 rigid, 4 non-rigid) and a3ob_rig_piece (the number of the rigid or non-rigid piece, which Unpose uses).

Inputs

  1. Input 1: Your mesh. The mesh with the weighted body (from Weight Transfer) and the accessories. Both groups below are point groups of this mesh.
  2. Input 2: Skeleton. The skeleton, for example from Rig Skeleton; the output of Rig Fit goes here as it is (its fitted skeleton is used). Its joint names decide which selections are bones and how they are spelled; its hierarchy says where a twist bone's weight goes.

Parameters

Parameters are in the order they appear on the node.

Target Group target

The accessory points to weight. Required. A point group or a primitive group (its primitives' points count). Each connected piece of the group is one piece, or each name when Pieces From is Names.

Type
Group picker (text; the menu lists the point groups and primitive groups of the input that are yours, without the bone groups (a primitive group counts as the points of its primitives; typing a bone group name still works) of the input, the arrow button picks in the viewport)
Default
(empty)

Source Group source

The points that give the weights (a point group or a primitive group): the body, or another accessory that already has weights. Points of it with no bone weight are ignored, with a warning. Not used when Rigid uses a picked bone.

Type
Group picker (text; the menu lists the point groups and primitive groups of the input that are yours, without the bone groups (a primitive group counts as the points of its primitives; typing a bone group name still works) of the input, the arrow button picks in the viewport)

(empty)

Mode mode

How the accessory is weighted.

Type
Menu
Default
Rigid

Choices:

  • Rigid rigid: Every connected piece of the target follows one bone or one fixed blend (a helmet, a pouch).
  • Non-rigid nonrigid: Each point takes the weights of the source under it, smoothed along the piece (a bandolier, a cable).

Rigid Uses use

How a rigid piece is weighted.

Type
Menu
Default
Auto
Shown when
Mode is Rigid

Choices:

  • Auto auto: The whole piece follows the one bone with the most source weight under it (weight 1).
  • Fixed blend blend: Every point gets the same mix of bones, the average of the source under the piece.
  • Bone bone: Every piece follows the bone you pick below.

Pieces From piecesfrom

How a rigid target is cut into pieces. Non-rigid mode always uses connected pieces.

Type
Menu
Default
Names
Shown when
Mode is Rigid

Choices:

  • Names names: Polygons with the same name are one piece, even when the parts do not touch (a helmet, its visor and its bolts). Polygons with no name, or a mesh without the name attribute, use connected pieces, and so does a mesh where every polygon has the same name (the node warns about that: give the parts their own names). A point shared by two names goes to the name with most of its polygons.
  • Connected Pieces connected: Every connected piece is weighted on its own.
