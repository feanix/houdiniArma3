Reference / Shelf tools

New P3D

Builds the starter network (Resolution 1, Geometry and Memory LODs, Assemble LODs, P3D Export) in the open SOP network or in a new Geometry object.

Use this to start a new model. It builds a small network for you: two LODs, a node to put them together and a node to export.

Where to find itThe A3OB shelf, button New P3D
Tool namea3ob_new_p3d

A shelf tool works on your scene or your settings when you click it. It is not a node, so it does not stay in your network.

Houdini tools for Arma 3 models. Based on Arma 3 Object Builder by MrClock, which continues ArmAToolbox by Alwarren.
