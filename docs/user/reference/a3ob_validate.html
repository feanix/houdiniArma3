Reference / Nodes

Validate

Checks a P3D geometry or a LOD geometry the way the export does and shows what is wrong. Changes nothing.

Run this node before you export. It looks for problems that Arma would reject or that break the model, and lists them as messages on the node. It does not change the geometry.

Houdini namea3ob_validate
Where to find itTab menu, A3OB, Validate
Inputs1

Inputs

  1. Input 1: P3D geometry or LOD geometry. The model to check: a whole P3D from Assemble LODs, or a single LOD.

Parameters

Parameters are in the order they appear on the node.

Errors Show As errorlevel

Type
Menu
Default
Error (stop here)

Choices:

  • Error (stop here) error: The node turns red and the nodes below it stop.
  • Warning (keep geometry) warning: The node turns yellow and the geometry keeps flowing; the text still starts with Error:. Saving stops on errors either way.

Warnings Count As Errors strict

Treat every warning as an error. Off by default: a warning can be what you meant.

Type
On or off
Default
Off
