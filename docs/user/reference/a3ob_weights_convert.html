Reference / Nodes

Weights Convert

Converts bone weights between P3D selections (point groups) and KineFX capture weights for the skeleton.

A bone weight lives in two forms. In a P3D file it is a selection named like the bone, with a weight for each point. KineFX nodes such as Joint Deform use capture weights instead. This node converts one form into the other for the skeleton on input 2.

Selections are matched to the joints ignoring upper and lower case. A selection that is not a bone (a component, a hidden selection) is left alone. A member with weight 0 (byte 255 in the file) counts as no weight.

Houdini namea3ob_weights_convert
Where to find itTab menu, A3OB, Weights Convert
Inputs2

Inputs

  1. Input 1: Geometry. The LOD geometry whose bone weights are converted (for example from Extract LOD).
  2. Input 2: Skeleton. The skeleton, for example from Rig Skeleton. Its joint names decide which selections are bones.

Parameters

Parameters are in the order they appear on the node.

Mode mode

Which way to convert.

Type
Menu
Default
Selections to Capture

Choices:

  • Selections to Capture tocapture: Reads the bone selections (point groups, with their a3ob_w weights) and writes capture weights (boneCapture) for the skeleton. Joint Deform can use them.
  • Capture to Selections toselections: Reads the capture weights and writes bone selections. A selection that is not a bone is left alone.

Selection Names case

How a bone selection is named when it is written. Only used by Capture to Selections.

Type
Menu
Default
model.cfg spelling
Shown when
Mode is Capture to Selections

Choices:

  • model.cfg spelling cfg: Names the selection like the bone in the skeleton (for example head). A selection that already exists under another spelling (Head) is renamed.
  • Keep existing spelling keep: A selection that already exists keeps its name. A new one is named like the bone.
