Reference / Nodes

Rig Skeleton

Builds the Arma 3 character skeleton as a KineFX skeleton, from a model.cfg and a pivots .p3d file. Each joint's X axis points down its bone to the next joint, and the hinge of elbows, knees, fingers and thumbs is on Z.

Builds the Arma 3 character skeleton as a KineFX skeleton (the kind that Rig Pose and Joint Deform use). The bones and their parents come from a model.cfg. Where each joint sits comes from a separate pivots .p3d file: the model.cfg only names the game's packed pivots file, which can't be read.

The face bones (Face_*) and the eyes are left out. A bone with no pivot is left out and listed on the node. A new node starts from the Samples files when the Arma 3 Samples folder is set in the Project root and presets tool.

Houdini namea3ob_rig_skeleton
Where to find itTab menu, A3OB, Rig Skeleton
InputsNone

Parameters

Parameters are in the order they appear on the node.

Model Config cfg

The model.cfg that holds the skeleton. This node reads exactly this one file. Arma also reads a <foldername>.cfg (which wins over model.cfg) and a <modelname>.cfg next to the model; if your skeleton is in one of those, pick that file. #include lines are not followed.

Type
File path
Default
(empty)

Skeleton skeleton

Which skeleton class of the file to build (the classes in CfgSkeletons, with their bone count). Empty means the first one that has bones. A class that inherits (skeletonInherit) gets the bones of the class it inherits from first.

Type

The choices are made when you open the menu, from the geometry or the settings.

Pivots File pivots

An editable pivots .p3d: its Memory LOD has one named selection per bone, and the first point of a selection is that bone's pivot. The game file named by pivotsModel in the model.cfg is packed and can't be read, so you point at the editable one here (the Samples have ManSkeleton_Pivots.p3d).
