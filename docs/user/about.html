About

A3OB for Houdini brings the Arma 3 model tools to Houdini.

What this is

A set of Houdini nodes and shelf tools to read, edit and write the .p3d model files of Arma 3. It is a port of Arma 3 Object Builder (A3OB), which does the same job in Blender.

Credits

  • Arma 3 Object Builder by MrClock. The ideas, the file format code and many of the options in these tools come from this Blender add-on.
  • ArmAToolbox by Hans-Jörg "Alwarren" Frieden. A3OB continues this earlier Blender add-on.

Thank you to both of them for the work and for sharing it under a free licence.

AI disclosure

The code, the tools and the documentation were written with AI assistance (Claude, by Anthropic). The project owner directed the work, tested it and checked it. If you would rather not use AI-assisted tools, that is completely fine. Two alternatives are Arma 3 Object Builder for Blender (A3OB, by MrClock) and Arma 3 Tools (including Object Builder), the official tools from Bohemia Interactive.

What’s not here yet

These parts of A3OB are not in this add-on yet:

  • model.cfg, skeletons and rigging.
  • PAA textures. Showing textures in the viewport is planned.
  • Terrain files: ASC heightmaps and Terrain Builder object lists.
