# houdini/

Houdini content root for the `a3ob_houdini` package. The package file
(`packages/a3ob_houdini.json`) adds this folder to `HOUDINI_PATH`, so Houdini
looks here for the usual subfolders.

| Folder        | Holds                                               | State |
| ------------- | --------------------------------------------------- | ----- |
| `otls/`       | The node assets, one text HDA folder per node (`a3ob_<kind>.hda/`). Generated by `scripts/build_hdas.py` from the node's parameter table; never edit or save them from the GUI (D13). | in use |
| `toolbar/`    | Shelf tools (`.shelf`). `a3ob_selection_browser.shelf` has the Selection browser tool. Each shelf script only calls into `a3ob_houdini`. | in use |
| `python3.13libs/` | Houdini startup scripts (`pythonrc.py`, `uiready.py`), if needed | not yet |
| `MainMenuCommon.xml`, `radialmenu/` | Menu entries                  | not yet |
| `config/Icons/` | Icons                                             | not yet |

Python modules do not go here: they live in `../python/` (`a3ob_core`,
`a3ob_houdini`), which the package puts on `PYTHONPATH`. How a node is built is
described in `../python/a3ob_houdini/README.md`.
